# ctnlist

ctnlist is a web-based mailing-list application originally created by Richard Royston Catto in 2009.

The application supports subscriber management, mailing lists, message templates, queued sending, message tracking, archives, suppression lists and related administration features.

## Version 5.0

ctnlist 5.0 is a major modernisation of the original application.

Planned changes include:

* PHP 8.3+
* Composer dependency management
* PostgreSQL
* Phinx database migrations
* Symfony Mailer
* Passwordless email authentication
* Improved security
* JSON APIs
* Modern JavaScript or TypeScript frontend components
* Refactored service and repository architecture
* Improved queue reliability and background processing

## Legacy versions

* `v4.3` - partial historical snapshot
* `v4.4` - final legacy baseline before 5.0 modernisation
